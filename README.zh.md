# 🗼 我要去巴黎（Je veux aller à Paris）— 法语词汇与动词变位学习应用

<p align="center">
  <img src="assets/icon-192.png" alt="我要去巴黎 Logo" width="120" />
</p>

**我要去巴黎（Je veux aller à Paris）** 是一款零依赖的法语学习网页应用与离线 PWA，专注于帮助你高效记忆法语高频词汇、掌握动词变位、训练法语听力听写，并内置个人错题本、单词本与跨设备进度备份功能，电脑与手机均可随时使用。

🌐 **在线访问：** https://kkwangela.github.io/french-learning/

---

## ✨ 核心功能

### 1. 🗂️ 间隔重复闪卡（SRS）
- 基于 **SuperMemo SM-2** 艾宾浩斯遗忘曲线算法自动安排复习间隔。
- 3D 翻转卡片展示法语发音、音标、词性与阴阳性，背面提供可点击查词的语境例句（单词释义保留英文原版解释）。
- 支持四级记忆评分：**重来 (1)**、**较难 (2)**、**记住 (3)**、**简单 (4)**。
- 支持按「全部内容」、「仅动词变位」、「仅核心词汇」或「📒 我的单词本」筛选复习。
- 支持键盘快捷键：`Space` 翻面，`1`–`4` 快速评分。

### 2. ⚡ 动词变位速练
- 高频覆盖法语四大核心时态：
  - **Présent（现在时）**
  - **Passé Composé（复合过去时，含 *avoir* / *être* 助动词与性数配合）**
  - **Imparfait（未完成过去时）**
  - **Futur Simple（简单将来时）**
- 内置法语重音符号快捷栏（`é`、`è`、`ê`、`à`、`â`、`ç`、`î`、`ï`、`ô`、`û`、`œ`）与连对计数（`🔥`）。

### 3. 🎧 听力与听写训练
- **动词听写**：听写动词变位与人称搭配。
- **连诵辨音**：专项攻克法语经典连诵陷阱（如 *Ils ont* vs *Ils sont*、*Vous avez* vs *Vous savez*、未完成过去时 *-ais* vs 复合过去时 *-é*）。
- **句子听写**：支持正常语速（`0.9x`）与慢速（`0.65x`）播放，提交后逐词高亮对比纠错。

### 4. 🔍 法语查词典、💬 点词悬浮查词 & 📒 单词本
- **法英双向查词典**：支持输入任意法语或英文单词查询（内置词库离线秒查 + 联网调用 Wiktionary/翻译词典查任意词汇 + 手动自定义生词），附带发音朗读、动词变位预览与历史记录。
- 在「例句填空」、「闪卡复习」、「高频词库」和「听力听写结果」中，点击任意法语单词都会弹出悬浮释义卡，显示英文释义、音标、词性/阴阳性、变位原形来源与法语朗读。
- 一键收藏到 **📒 我的单词本**（自动保留来源例句），并可随时一键启动单词本专属 SRS 闪卡复习。

### 5. 📕 错题本与专项重练
- 自动收录变位速练、听力听写、例句填空和闪卡复习中做错的题目。
- 支持错误答案与正确答案对比、法语发音回听，以及「🎯 专攻错题」强化训练模式。

### 6. 📖 动词变位表、🧩 例句填空、📚 高频词库与 💡 记忆规律
- 收录 30+ 高频法语动词 6 大时态完整变位表，支持单条与整表朗读。
- 提供真实日常法语例句填空、分类高频词表以及不规则动词助记规律。

### 7. 🌐 中英文界面切换 & 📦 跨设备备份恢复
- 顶部一键切换 **中文 / English** 界面语言（中文模式下仅界面标签为中文，单词释义保持英文）。
- 一键导出/导入 **JSON 备份文件**，完整迁移复习曲线、错题本与单词本。
- 桌面端采用清晰的**左侧边栏导航**，手机端自动收纳为滑出抽屉，支持浅色/深色主题与离线访问。

## 📱 安装到手机桌面（PWA 离线应用）

1. 在 **iPhone Safari**（安卓用 **Chrome**）打开 https://kkwangela.github.io/french-learning/ 。
2. 点击底部 **分享（📤）** → **「添加到主屏幕」** → **添加**。
3. 桌面将出现喝咖啡巴黎小猫图标与「我要去巴黎」名称，点击即可全屏离线使用。

如需使用 Xcode 打包原生 iOS 应用，请查看 [ios/README.md](ios/README.md)。

---

## 🚀 本地运行

### 方式一：直接打开网页
在浏览器中直接双击打开 `index.html` 即可使用。

### 方式二：启动本地服务（同时输出局域网地址方便手机测试）
```bash
./start.sh
```
